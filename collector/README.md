# הקמת קולט המיפויים (Google Sheets)

הקולט הוא גיליון Google עם סקריפט קצר. כשמרצה לוחץ באתר על **"שליחה לרשות"**, המיפוי נכתב כשורה בגיליון.
רק מי שהגיליון משותף איתו יכול לראות את הנתונים. ההקמה נעשית פעם אחת, וזמנה כ-10 דקות.

## 1. יצירת הגיליון
1. מתחברים לחשבון Google של הרשות (עדיף חשבון מוסדי או משותף, לא אישי).
2. נכנסים לכתובת **https://sheets.new**. נפתח גיליון חדש.
3. נותנים לו שם, למשל: `מיפוי מיומנויות – מיפויים`.

## 2. הדבקת הסקריפט
1. בתפריט: **תוספים ← Apps Script** (באנגלית: Extensions ← Apps Script). נפתחת לשונית חדשה.
2. בקובץ `Code.gs` מוחקים את כל מה שכתוב.
3. מעתיקים את כל התוכן של הקובץ `collector/Code.gs`
   (https://github.com/elearningunit/skills-mapping/blob/main/collector/Code.gs ← כפתור ההעתקה שליד "Raw")
   ומדביקים.
4. שומרים (Ctrl+S).

## 3. הרצה ראשונה ואישור הרשאות
1. בסרגל העליון, ברשימת הפונקציות, בוחרים **setup** ולוחצים **הפעלה** (Run).
2. מופיעה בקשת הרשאה: **בדיקת ההרשאות** ← בוחרים את החשבון.
3. אם מופיע "Google לא אימתה את האפליקציה": **מתקדם** ← **מעבר אל ... (לא בטוח)** ← **אישור**.
   זה תקין: הסקריפט שלכם ופועל רק על הגיליון הזה.
4. חוזרים לגיליון. נוצרה בו לשונית **מיפויים** עם שורת כותרות.

## 4. פרסום ככתובת אינטרנט
1. ב-Apps Script: **פריסה ← פריסה חדשה** (Deploy ← New deployment).
2. ליד "בחירת סוג" לוחצים על גלגל השיניים ← **אפליקציית אינטרנט** (Web app).
3. ממלאים:
   - **תיאור:** קולט מיפויים
   - **הפעלה בתור:** אני (Execute as: Me)
   - **למי יש גישה:** כל אחד (Who has access: Anyone)
4. **פריסה** (Deploy) ← מעתיקים את **כתובת אפליקציית האינטרנט**. היא מסתיימת ב-`/exec`.

"כל אחד" נדרש כדי שמרצים יוכלו לשלוח בלי להתחבר. זה **לא** חושף את הגיליון: הכתובת רק מקבלת מיפויים ואינה מחזירה נתונים.

## 5. בדיקה
פותחים את הכתובת בדפדפן. אמור להופיע: `{"ok":true,"service":"skills-mapping-collector"}`.

## 6. חיבור לאתר
שולחים את הכתובת למפתח. הוא מעדכן את `COLLECTOR_URL` בקובץ `src/config/collection.ts`, ואחרי הפרסום מופיע באתר הכפתור **"שליחה לרשות"**.

## מה נשמר
שורה לכל מיפוי, עם אותן 40 עמודות כמו בקובץ ה-CSV, ועמודה ראשונה `received_at` (זמן הקבלה).
שליחה חוזרת של אותו מיפוי (אחרי תיקון) **מעדכנת** את השורה הקיימת ואינה יוצרת כפילות.
הסקריפט בודק כל שליחה ודוחה נתונים שאינם במבנה הצפוי.

## הודעות במייל (רשות)
בראש הקובץ `Code.gs` יש שורה `var NOTIFY_EMAIL = '';`. כותבים בה כתובת (או כמה כתובות מופרדות בפסיק), למשל
`var NOTIFY_EMAIL = 'name@example.org';`. בגרסה הציבורית ב-GitHub השורה ריקה בכוונה.
אחרי השינוי מריצים פעם אחת את `testNotification` (מאשרים את הרשאת המייל), ואז מפרסמים גרסה חדשה (ראו למטה).
ההודעה כוללת קורס, פקולטה, מחלקה, שנה, תאריך וקישור לגיליון, אבל לא את שם המרצה.

## עדכון הסקריפט בעתיד
מדביקים את הגרסה החדשה ← **פריסה ← ניהול פריסות** ← עריכה (עיפרון) ← **גרסה: חדשה** ← פריסה.
כך הכתובת נשארת זהה, ואין צורך לעדכן את האתר.

## פרטיות
- הגיליון מכיל שמות מרצים. משתפים אותו רק עם צוות הרשות, ולא ב"כל מי שיש לו את הקישור".
- כתובת הקולט גלויה בקוד האתר, ולכן תיאורטית אפשר לשלוח אליה מיפוי מזויף. הסקריפט דוחה נתונים לא תקינים,
  ושורות חשודות אפשר למחוק ידנית.
