# ממשק הרשות – התקנה

ממשק הרשות הוא אפליקציית Google Apps Script נפרדת מהקולט. רק החשבון `elearningunit@g.ariel.ac.il` יכול להיכנס אליה.
היא קוראת את הגיליון של הקולט, ושומרת בו רק את הכרעות הרשות (עמודות `decision` ו-`status`) ואת היומן.

**תנאי מוקדם:** הקולט מעודכן לגרסה 2, ו-`migrate` הורץ (ראו `collector/README.md`).
בלי זה כל השורות יופיעו "לבדיקה", ולא יהיה אפשר להכריע.

## התקנה (כ-15 דקות, פעם אחת)

1. **פרויקט חדש:** מחוברים לחשבון `elearningunit@g.ariel.ac.il` ← נכנסים ל-https://script.google.com ← **פרויקט חדש**.
   משנים את השם למעלה ל-`ממשק הרשות`.
2. **קוד השרת:** בקובץ `Code.gs` מוחקים הכול ומדביקים את התוכן של
   https://github.com/elearningunit/skills-mapping/blob/main/admin/Code.gs (כפתור ההעתקה שליד "Raw"). שומרים (Ctrl+S).
3. **קובץ המסך:**
   - לוחצים **+** ליד "קבצים" ← **HTML** ← קוראים לקובץ בדיוק `index`. העורך יוסיף `.html` לבד.
   - מוחקים את מה שבתוכו, ומדביקים את התוכן של
     https://github.com/elearningunit/skills-mapping/blob/main/admin/apps-script/index.html
     (כפתור ההעתקה שליד "Raw"). הקובץ ארוך, ולכן ההדבקה יכולה לקחת כמה שניות. שומרים.
4. **הגדרות:** גלגל השיניים (**הגדרות הפרויקט**) ← **מאפייני סקריפט** ← מוסיפים שני מאפיינים:

   | מאפיין | ערך |
   |---|---|
   | `SHEET_ID` | המזהה של גיליון המיפויים: בכתובת הגיליון, החלק שבין `/d/` לבין `/edit` |
   | `ADMIN_EMAILS` | `elearningunit@g.ariel.ac.il` |

   **שמירת מאפייני הסקריפט.**
5. **פרסום:** **פריסה ← פריסה חדשה** ← גלגל שיניים ← **אפליקציית אינטרנט**:
   - **הפעלה בתור: אני**
   - **למי יש גישה: רק אני**

   ← **פריסה** ← מאשרים הרשאות (בדיקת ההרשאות ← החשבון ← מתקדם ← מעבר אל… ← אישור).
6. **כניסה:** פותחים את **כתובת אפליקציית האינטרנט** ושומרים אותה בסימניות. זה מסך הניהול.

## אבטחה

- **"למי יש גישה: רק אני":** Google עצמו חוסם כל חשבון אחר, עוד לפני שהקוד רץ.
- **שכבה שנייה:** כל פעולה בשרת בודקת שהמשתמש ברשימת `ADMIN_EMAILS`. אם הרשימה ריקה, אף אחד לא נכנס.
- **הנתונים לא חלק מקובץ המסך:** הם נשלפים מהגיליון רק אחרי בדיקת ההרשאה. אין נתוני מרצים באתר הציבורי או ב-GitHub.
- **שום הכרעה לא מוחקת נתונים:** משתנות רק העמודות `decision` ו-`status`, וכל הכרעה נרשמת ביומן עם הכתובת של מי שביצע אותה.

## עדכון בעתיד

כשהמסך מתעדכן, מדביקים מחדש את `index.html` (ואם השתנה, גם את `Code.gs`) ←
**פריסה ← ניהול פריסות** ← עיפרון ← **גרסה: גרסה חדשה** ← **פריסה**. הכתובת נשארת זהה.

## למפתחים

- המסך: `src/admin/` (React). בנייה לקובץ ההתקנה: `npm run build:admin`, שיוצר את `admin/apps-script/index.html`.
  תהליך ה-GitHub נכשל אם הקובץ במאגר לא תואם לקוד.
- תצוגה מקומית עם נתוני דוגמה בדויים: `npm run build:admin-demo` ← `dist-admin-demo/admin-demo.html`.
  נתוני הדוגמה לא נכללים בקובץ ההתקנה.
- בדיקות: `tests/admin-server.test.ts` (הרשאות והכרעות מול גיליון מדומה, יחד עם הקולט), `tests/admin-model.test.ts`,
  ו-`tests/e2e/admin.e2e.ts` (דפדפן, מול קובץ ההתקנה, עם `google.script.run` מדומה).
